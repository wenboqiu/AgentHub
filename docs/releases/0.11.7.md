# 0.11.7 全应用文本展示统一支持 markdown

上一版只在对话流渲染 markdown，这一版铺到所有展示 agent / 机器生成文本的地方。只换客户端安装包即可。

- **任务产物按 markdown 排版**：过去整份产物用等宽 `pre` 原样显示，现在标题、列表、表格、代码块正常排版；编辑与导出 .md 不变。
- **验收摘要**：摘要里的最近一条助手回复按 markdown 排版。
- **助手气泡**：角色助手的回复按 markdown 排版，自己发的消息保持原文。
- **项目近况**：机器记的进展条目按 markdown 排版。
- **会话列表摘要**：列表卡片上的 AI 摘要按 markdown 排版（紧凑变体，仍三行截断、点击展开收起）。
- **分支预览**：从此处分支的引用预览按 markdown 排版。

保持原文不渲染的：用户可编辑的输入框（任务备注、清单、任务单表单等）、单行截断的标题、时间线里的截断片段（避免截断处语法残缺渲染出怪样）。

实现：Markdown 组件加 compact 紧凑变体；`.md` 样式泛化为全应用通用，复用主题变量，浅色/深色自动适配。
