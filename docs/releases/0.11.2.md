# 0.11.2 气泡视图跟着窗口走

只改界面，服务端不动；换客户端安装包即可。

- **气泡区随窗口自适应**：会话页图模式的舞台过去高度写死（总览随项目数算到最多 560，展开按面积估到最多 900），窗口拉高、拉窄都不重排。现在高度按「窗口还能给多少」算（视口高减去标题区，夹在 320–1000 之间），并同时监听窗口缩放与容器尺寸，拖动窗口时即时重排。
- **气泡大小跟着舞台缩放**：大窗口球放大一点（最多 1.45 倍），免得几个球散在空地上；小窗口只轻微收（不低于 0.95 倍），气泡里的文字不被挤烂。
- **挤不下才长高**：舞台先吃满可用高度，确实放不开时再按 1.15 倍往下长（总览上限 1000、展开上限 1400），靠页面滚动看全，不再为了几个球硬撑一屏、也不再让球叠在一起。

实测同一页面连续改窗口：1440×900 → 1760×1280 → 900×640 → 回到 1440×900，舞台 588 → 968 → 337 → 588，可逆无漂移；640×520 极小窗下气泡无重叠、无出界。
