# 0.15.0

agent、角色、项目都有了头像；远程执行改成默认开启，开着 AgentHub 但没开开关的电脑不再显示成「离线」；执行边界收成一行摘要；豆包会话能看到图片。

## 新增

- **头像**
  - 内置一批网上的 agent 形象作为默认头像：Claude 用 Clawd，Codex 用终端小钟，豆包用 Q 版女生，WorkBuddy 用 OpenClaw 像素小龙虾，CodeBuddy 用 QQ 企鹅，ZCode 用 GLM 猫耳娘；另有大肥鱼（鲸鱼娘）等可选。
  - 设置 → 外观 → agent 头像：每个 agent 可选网上形象、首字母、emoji，或上传图片（裁成 96×96）；存在账号上，电脑和手机同步，一边改了另一边实时更新。
  - 会话流里每条 agent 回复前显示头像（含豆包窗口抓到的回复）。
  - 角色、项目编辑页可换头像：角色没设时跟随执行工具的 agent 头像，项目没设时显示项目名首字母；两处列表也显示头像。
- **豆包会话显示图片**：读豆包本地缓存，把消息里的图片配上显示，对不上的仍是「[图片]」占位；单个换行不再被吞掉。
- **历史同步带上用户附图**：Claude / WorkBuddy 会话「刷新电脑上的记录」时，用户发过的图片一起带回来。

## 变更

- **远程执行默认开启**：新装直接开启；老电脑升级后第一次启动会打开一次，之后手动关掉就保持关。
- **「开着，没开远程执行」不再显示成离线**：远程执行关着时，客户端也连服务端，但声明不接活；派活和项目配置的电脑下拉会标出「（开着，没开远程执行）」，选中时提示去那台电脑的设置里打开开关；派给它的单会排队，开关一开就自动开始。
- **执行边界只露一行摘要**：任务详情和任务单里默认显示「整个项目 · 不联网 · 不推远端 · 不跑自定义脚本」这样一行，点「修改」才展开目录和三个开关；去掉场景下拉、「填上」和说明输入框。边界一般由项目经理在生成任务单时写好，空着也能正常改代码、跑测试。

## 修复

- **Claude 放出后台子代理后被提前标成「完成待确认」**：Stop hook 到达时，后台子代理还没回报就保持运行中（超过 2 小时未回报的按遗留处理）。

## 升级

服务端和客户端都有改动，**先升服务端再升客户端**：
- 头像存取（`/prefs`、角色 / 项目的 `avatar`）在服务端，老服务端上头像只能看默认形象，改了存不住。
- 「开着，没开远程执行」的识别在服务端；新客户端连老服务端时，没开远程执行的电脑会被老服务端当成在线，派过去的单客户端会直接回失败并说明原因，不会卡在运行中。
