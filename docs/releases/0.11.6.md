# 0.11.6 对话流支持 markdown 格式化显示

agent 回复不再是一坨带星号井号的原文，按 markdown 排版显示。只换客户端安装包即可。

- **agent 回复按 markdown 渲染**：标题、有序/无序列表、代码块（行内 + 围栏）、表格、引用、分隔线、任务清单、删除线、自动链接（GFM）都正常排版；流式输出时随内容增长逐步渲染。
- **安全默认**：不渲染原始 HTML（防注入），链接统一新窗口打开，不会把 Tauri 窗口原地导航走。
- **用户消息保持原文**：自己输入的内容仍按纯文本显示，消息里的下划线、星号不会被误当格式。

实现：`react-markdown` + `remark-gfm`，样式复用现有主题变量，浅色/深色自动适配。
