# 0.11.21

修复 CodeBuddy / WorkBuddy 通道派活即失败。

## 修复

- **CodeBuddy 派活报「进程异常退出（1）：unknown option '--permission-prompt-tool'」**：该参数只有 Claude Code 支持，CodeBuddy / WorkBuddy 同源 CLI 2.x 没有它，之前三通道共用同一份参数导致 codebuddy 一启动就被 CLI 拒绝。现在只有 Claude 通道带 `--permission-prompt-tool stdio`，CodeBuddy / WorkBuddy 通道去掉该参数（其余 stream-json、--permission-mode、--resume/--fork-session 均保留，这些 2.181.0 都支持）。

## 说明

- CodeBuddy 通道去掉该参数后，权限请求不再走 stdio 提示工具，headless 下的授权行为由 CLI 自身的 `--permission-mode default` 决定；审批卡联动后续版本再对齐。
- Claude 通道参数完全不变。
