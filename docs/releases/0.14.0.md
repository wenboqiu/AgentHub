# 0.14.0

新增「统计」页：按日 / 周 / 月看会话、运行、任务的数量和趋势。同一版补记上一版已带上、但说明里没写的执行授权改动（自动档配额、规则表、续聊不改范围）。

## 新增

- **统计页**（顶层导航「统计」）：按日 / 周 / 月看新建与活跃会话、消息数、运行次数与时长、token / 费用、新建与完成任务、平均完成时长、验收打回数；可按 agent / 项目 / 模型拆分，和紧邻的上一段对比，并显示任务当前各状态数。柱状图悬停或点击看具体数字。
  - 服务端每小时把最近 28 天重算进日汇总表（`daily_stats` / `daily_model_stats`），更早的封存不动；周 / 月由日数据合并。会话只保留 30 天、运行 90 天，汇总表让更早的数字留得住。
  - 新接口 `GET /stats?from&to&granularity=day|week|month&by=none|agent|project|model`；按 `STATS_TZ`（默认 `Asia/Shanghai`）切天。口径与限制见 [数据统计设计](../stats-design.md)。

## 变更（0.13.0 已带上，补记）

- **自动档配额按任务算**：授权模式为「自动」时，范围内自动放行的上限从账号级每小时 60 次（与代批共用）改为每个任务每小时 300 次，只作为防跑飞的熔断线。
- **规则表补常用工具链**：`flutter` / `dart` 的测试、分析、构建、格式化，`adb devices` / `logcat` / 只读 `shell` / `install`，`docker` / `gh` 的只读命令，不带 `-i` 的 `sed` 和不调 `system` 的 `awk` 直接放行；改设备、改容器、GitHub 写操作归灰色地带交给你。「格式化磁盘」红线只认带盘符的 `format C:`，不再误伤 `dart format`、`npm run format`。规则版本 `referee-2026-11b`。
- **续聊不改授权范围**：在挂着已签授权任务的会话里追加消息，执行器拿到的是同一份冻结范围；消息里写「可以 push 了」也不放宽，换范围只能新开任务。
- 删掉没有调用方的通知语义过滤接缝；「投机执行」改名「预摘要」（只改名，行为不变）。

## 升级

服务端和客户端都有改动，**先升服务端再升客户端**：老服务端没有 `/stats`，新客户端的统计页会报错。服务端首次启动会给 `sessions` 加 `first_seen_at` 列、建两张汇总表，30 秒后做一次全量汇总（首次按最早任务日与 90 天前较早者回填）。
