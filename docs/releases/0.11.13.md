# 0.11.13 WorkBuddy 读完就收

在 WorkBuddy 里看完一轮回复，AgentHub 的「待处理」跟着消失，不用再到手机上点「已处理」。服务端有改动，先升服务端再升客户端；Android 不用为此重新打包。

- **已读同步**：电脑端每 15 秒只读核对 WorkBuddy 的已读标记（`~/.workbuddy/workbuddy.db` 的 `sessions.unread`），确认「这一轮你已经在 WorkBuddy 里看过」就把那一轮的完成提醒标为已处理。
- **只清该清的那一条**：只认 `done` / `aborted`，同账号、同机器、同一完成时间；等授权的事项照旧要你拍板，标题和正文不动。连续两次核对一致才上报，避免 WorkBuddy 刚跑完那一小段误判。
- **没看过的不动**：自动跑完、没人打开过的会话（比如定时任务单监听）仍旧在待处理里等确认，照旧 2 小时过期。

实现见 [WorkBuddy 已读同步](../workbuddy-read-sync.md)。需要同时升级服务端与电脑端。
