# 0.14.1

时间提醒不再在所有 tab 顶部常驻，并进任务页的「等你处理」。

## 变更

- **时间提醒并进「等你处理」**：以前提醒条渲染在首页顶部，会话 / 任务 / 目标 / 日历 / 统计五个 tab 都显示，要手点「已处理」才消失，过期的多了会把首屏占满，还和「等你处理」是两处重复的待办入口。现在它是收件箱的第六类：带「提醒」标签，写明任务 / 目标、开始时间到了 / 已到截止时间和具体时间，点整行打开对应任务或目标，右边「已处理」。
- **任务 tab 角标计入提醒**：任一 tab 下，有到点没处理的提醒，任务标签上都会有数字。
- **筛选对提醒同样生效**：任务页选了项目 / 角色时，任务提醒按它自己的项目和角色判断；目标没有项目，只在不筛选时出现。
- 到点的桌面通知不变。

## 升级

只有客户端改动，只换客户端安装包即可，服务端不用动。

## 验证

- 前端 `tsc --noEmit` 通过；`vite build` 通过。
- 用预览台（假数据）看过：「等你处理」里提醒行的样式与其他类型一致，点「已处理」后该行消失、计数同步减少，旧的顶部常驻条不再出现。
- 没有在真实客户端里看过。
