# 0.11.22

排查「装完自动开启的程序闪退」：加启动/退出诊断日志。

## 新增

- **启动诊断日志** `%LOCALAPPDATA%\AgentHub\boot.log`，记录五个节点：
  - `start`：进程启动（含 pid 与命令行参数）——若连这行都没有，说明进程根本没跑起来（环境变量丢失、RunAsUser 失败等）；
  - `PANIC`：Rust panic 钩子；
  - `second-instance 连入`：单实例插件收到重复启动事件——自动拉起的新进程如果触发这行，说明它把「旧实例未退净」误判成了重复启动；
  - `setup done`：托盘建好、进入事件循环——`start` 之后没有这行 = 卡在初始化；
  - `ExitRequested / Exit`：应用主动退出及退出码。
- 日志位置自带降级：LOCALAPPDATA 不可用时退到 TEMP / exe 同目录（这本身就是「环境变量缺失」的证据）。

## 背景

用户反馈：交互式安装完成后自动拉起的 AgentHub 托盘无图标、进程消失（手动再开则正常）。已有排查排除了崩溃事件与单实例竞态的直接复现，本轮加入日志等下次真实安装时定位。
