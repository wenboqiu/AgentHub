# 0.13.0

点开文件看内容、任务标题前带序号；修了两处「任务被提前当成做完」的问题，以及项目没登记目录时派活报错看不懂的问题。

## 新增

- **点击文件路径预览**：任务页「证据 → 文件」、对话流 / 任务产物 / 最近回复里形如 `docs/xxx.md` 的行内路径可以点开。`.md` 按 Markdown 渲染，其他文件显示原文，超过 512KB 只显示前面部分。文件在执行任务的那台电脑上：服务端按任务 / 会话反查电脑和目录，经 WS 向电脑端要；电脑端只读该目录内、非禁用目录的 UTF-8 文本；只写裸文件名时在目录里找唯一同名文件，有多个同名会列出来。电脑不在线会提示。
- **任务序号**：看板、「等你处理」、任务详情标题、日历、会话里挂接的任务、已生成任务的任务单，标题前都带 `#29` 这样的序号。

## 修复

- **agent 放出后台子代理后被提前结束**：执行器以前收到第一个 `result` 就关 stdin，进程退出把后台子代理一起杀掉（任务 #29 就是这样只读了代码、什么都没写出来）。实测 `claude -p` stream-json 下，stdin 保持打开时后台完成后 CLI 会自己接着开下一轮，所以现在按 `task_started` / `task_notification` / `background_tasks_changed` 跟踪后台任务，还有没完成的就不结束；30 分钟没有任何输出才兜底结束。
- **任务被提前转进待验收**：会话的 Stop hook 报「本轮结束」时，只要这个会话还有在跑的运行，就不再转待验收，等运行真正结束再转。任务已在待验收时挂接会话又跑完一轮，会重新生成交付摘要、交付物快照和产物。
- **项目没登记目录 / 多台电脑在线没指明时，派活报错看不懂**：以前报「电脑名须为1–4000字符」（400），按项目目录挑电脑的兜底也因此从没生效过。现在电脑可以先留空，按项目目录登记的那台派；派不出去统一返回 409，并说清是「项目还没登记目录」「有 N 台电脑在线，请在任务上指定一台」还是「没有可派的电脑」。多台在线不替人随便挑一台。任务页、任务单、发单表单的提示同步改成「确认后派不出去」。

## 升级

服务端和客户端都有改动，**先升服务端再升客户端**：执行器（后台任务、文件预览）在客户端里，文件预览接口和不提前转待验收在服务端里，只升一边功能不完整；老执行器收到 `file.request` 会忽略，预览会一直超时。
