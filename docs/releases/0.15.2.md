# 0.15.2

ZCode 同一个权限请求不再弹好几张卡；Claude 的权限确认都能显示成「等待授权」；会话上显示还有几个后台子代理在跑。

## 修复

- **ZCode 同一个权限请求弹出好几张审批卡**：ZCode 没及时收到答复会按退避（约 0 / 1 / 2 / 4 / 8 / 10 秒）重发同一个请求，以前每次都建一张卡，同一条命令要点五六次。现在按同一次工具调用（`toolCallId`，其次 `requestId`）合并成一张：等你决定期间的重发只记下来，点一次就一起答复（超时拒绝同理）；刚答复过又迟到重发的，按同样的决定直接回，不再弹卡。两次不同的调用即使命令一样，仍各自弹卡。
- **Claude 的部分权限确认不显示为等待授权**：接入 PermissionRequest hook，PreToolUse 返回 ask 等需要确认的情况也会把会话标成「等待授权」。

## 新增

- **后台子代理数量**：Claude 放出后台子代理时，侧栏和会话页头部显示「运行中 · N 个后台任务」（仅在运行中且数量大于 0 时显示）。

## 升级

后台子代理数量需要服务端（`sessions` 加 `bg_tasks` 列），**先升服务端再升客户端**；老服务端上不显示数量，其余功能不受影响。ZCode 合并审批卡只在客户端。

## 验证

- 前端 `tsc --noEmit`、`vite build` 通过；`cargo test` 189 项通过（新增 ZCode 权限请求合并用例）。
- ZCode 合并审批卡的问题从线上会话记录确认（同一条命令 5 / 9 张卡、按退避节奏到达）；修复后尚未在真实 ZCode 会话里复测。后台子代理数量与 PermissionRequest hook 由另一会话实现，本次未复核。
