# 0.11.8 对话页默认气泡图，本机名改用系统真名

这一版有服务端改动（`POST /machines/rename`），**先重新部署服务端再升客户端**；只升客户端也不会坏，只是改名时旧记录迁不过去。

- **对话页默认气泡图**：新装 / 没选过展示方式的配置，打开对话页就是气泡图（按项目聚成气泡，点一下展开会话）。设置 → 外观里改成下拉选择（气泡图 / 列表），选过之后以你的选择为准——老配置里那个「没勾过」的 false 只做一次性迁移，不会把你手动选的列表改回去。
- **本机名取系统真名**：macOS 从访达 / LaunchAgent 启动时拿不到 `HOSTNAME`，早先兜底成了 `my-pc`，项目配置下拉里就像多了一台陌生电脑；现在优先读 `scutil --get ComputerName`（访达「共享」里显示的名字），再退回 hostname 命令，旧配置里存着 `my-pc` 这类占位名会在启动时换回真名并写回。
- **改名带动旧记录迁移**：服务端新增 `POST /machines/rename`，把旧名下的会话、运行记录、项目目录一起改到新名（同名合并、不重排目录）。设置里改「本机名称」也会触发同样的迁移，不再留下一台「名字没人用的电脑」。迁移在后台跑，失败只影响显示，不影响启动。
