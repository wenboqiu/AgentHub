# 0.15.3

项目经理能看懂 ZCode 的命令了；会话里成串的重复授权记录折叠显示；Claude 终端会话的权限确认可以在 AgentHub 里处理；会话页崩溃不再整页白屏。

## 新增

- **在 AgentHub 里处理 Claude 终端会话的权限确认**：终端里的 Claude 弹权限确认时，客户端最多等 25 秒你在 AgentHub 里的决定（远程拒绝；放行需另开开关）。总开关 `hookRemoteApprove` 和远程放行开关 `hookRemoteAllow` 默认都关；超时或没连上时不表态，终端照常弹确认框。

## 修复

- **项目经理把 ZCode 的命令都判成「看不懂」**：ZCode 送来的命令审批是整份入参 JSON（`{"command":"…","description":"…"}`），以前整串当命令拆，第一个词成了 `{"command":"cd`。现在先取出 `command` 再按规则判：`cd 项目 && git diff …`、`grep …` 这类只读命令直接放行，推远端照样问，强推、删目录、写到项目外仍是硬红线。
- **`2>/dev/null` 被当成「输出到项目外」**：丢弃输出（`/dev/null`、`NUL`）不再算越界。
- **会话里成串的重复授权记录**：老版本碰上 ZCode 重发权限请求时写下的「请求授权 / 已允许」，相邻相同的折成一条并标「×N」；库里数据不动，只折授权类消息。
- **会话页渲染出错时整页白屏**：加了错误边界，显示报错内容，换个会话自动恢复；错误同时记进 `localStorage`（`agenthub.lastError`）。

## 升级

服务端有改动（ZCode 命令裁决、终端会话权限确认的消息与 `approvals.can_allow` 列），**先升服务端再升客户端**。
