# 0.12.0

任务界面重排：看板并进任务页，页首一个「等你处理」收件箱；任务详情从四个子 tab 改成一张按状态变形态的单页。

## 新增

- **「等你处理」收件箱**（任务页页首）：待授权、待验收、卡住、会话建议、任务单五类事都在这一处，每行直接操作（允许 / 拒绝、去验收、重新派发 / 退回待办、生成任务单、查看并确认）。导航只留「任务」一个角标，数的就是这里的件数。
- **任务详情状态卡**：最上面一张卡按任务现在的状态给该做的事——
  - 待验收：它说做了什么 + 证据 + 逐项通过 / 打回 + 验收通过，判断和操作在同一屏；
  - 待授权：内联允许 / 拒绝（Codex 提问类给「去回答」）；
  - 运行中：最近 3 条活动、打开会话、插一句话、停止；
  - 卡住 / 排队：重新派发、换台电脑派、退回待办 / 取消排队；
  - 待派发：谁来做 + 从哪开始，直接派发，「补一句话再派…」可选；
  - 普通待办、已完成各有对应形态。
- **任务单上能改执行边界**：确认前可改，确认时随单冻结（服务端 `POST /proposals/:id/confirm` 接受 `constraints`）。

## 变更

- 顶层导航去掉「看板」：排队 / 在跑 / 卡住并入任务页的「在跑」与收件箱。
- 任务单展开后默认只露 要做什么 · 谁来做 · 怎么算完 · 按钮；说明、优先级、执行边界、证据收进「更多」。「只建任务」改名「先存为待办」，「让项目经理重写」「忽略」收进「⋯」菜单。
- 任务详情去掉 概览 / 执行 / 过程 / 结果 四个子 tab：说明、产物、过程依次排在状态卡下面，目标、优先级、边界、时间提醒、计时进右侧栏（窄屏落到下面）。
- 待办任务派发不再强制填「第一条消息」，默认用任务说明。
- 「会话」tab 不再挂任务单角标（已并入「任务」角标）。

## 升级

服务端有改动，**先升服务端再升客户端**：只换客户端时，任务单上改的执行边界会被老服务端忽略。
