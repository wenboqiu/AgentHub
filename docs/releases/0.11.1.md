# 0.11.1 折叠屏修复、图模式收尾、完成态自动过期

0.11.0 之后的一批界面收尾与服务端小改动，主要是图模式（气泡视图）打磨和手机端顶部栏在折叠屏上的修复。

## 界面

- **会话侧栏分段折叠**：会话详情页左侧列表按「待处理 / 进行中 / 已处理」三段各自折叠，前两段默认展开，折叠状态记在本地。
- **图模式气泡显示名称**：总览的项目球内直接显示项目名，展开态会话球内显示状态、缩略对话标题与 agent 名。
- **已处理去球化**：底部已处理小球带改为一行「已处理 N」折叠标题 + 纯列表（agent / 项目 / 标题 / 状态），点击跳会话。
- **待处理文案与配色统一**：待处理气泡改说「完成待确认 / 中断待确认」（告诉你需要做什么），配色统一为暖色（等待授权红、完成琥珀、中断深红），运行中蓝色。

## 折叠屏修复

- **顶部栏溢出**：折叠屏（约 CSS 914px 宽）与中窄宽度下，绝对居中的 tab 胶囊会盖住连接状态、设置按钮被挤出屏幕。现在居中断点放宽到 1200px，之下 tab 改弹性布局在胶囊内部滚动，设置按钮不再被挤走；极窄屏逐步降级（藏版本号、藏 tab 图标）。
- **连接状态文字禁止换行**，避免在窄 header 里折成两行。

## 服务端

- **完成态自动过期**：`done` / `aborted` 的待处理提醒挂超过 2 小时没人确认，自动转入已处理并逐条广播；等待授权不过期。默认 60 秒一轮，`RouteOptions.pendingExpireMs` 可调。**这一版服务端有改动，先升服务端再升客户端。**
