# AgentHub 0.5.1

日期：2026-11-02。本版合并同一工作区各会话的全部功能修改，替代此前分别打包的 0.5.0 回复操作包和 Codex 已读修复包。

## 内容

- 助手逐条回复支持复制、赞／踩、朗读／停止、指定回复处分支；Claude Code 与 Codex 均使用原生上下文边界。
- Codex Desktop 已读状态同步至 AgentHub“已处理”，旧回执不能清除新回复，待授权事项不受影响。
- Claude Code 原终端仍打开时，通过认证的本机收件管道续聊并跟踪回复；停止跟踪不会终止原终端。终端关闭时恢复原会话。
- 实验性豆包 Windows 客户端状态监听，支持标题、运行／完成／中止、桌面与 Android 提醒和跳转窗口；暂不支持完整对话、授权、远程续聊或分支。
- Android 原生剪贴板和系统 TTS；通知识别豆包来源。

## 验证

前端测试 9/9，服务端检查及测试 59/59，Rust 测试 65 项通过，1 项需要显式指定豆包日志目录的环境测试跳过；前端生产构建通过，Git diff 格式检查通过。

此前已验证 Claude 原终端认证管道与消息记录，以及两种 agent 的指定回复原生分支；详见 [原终端续聊](../claude-terminal-chat.md)、[回复操作](../reply-actions/README.md) 和 [已读同步](../codex-read-sync.md)。这些功能文档中的旧提交／独立包状态属于开发阶段记录，本次以合并发布为准。

Android 真机朗读出声、用户现有交互终端的端到端续聊尚未验收；实际语音取决于设备 TTS 引擎和语言包。豆包适配的日志格式可能随客户端升级变化。

## 更新

服务端、Windows 电脑端和 Android 客户端应一起更新到此发布版本。安装包和服务端源码包位于 `artifacts.local/releases/0.5.1/`，文件名与校验清单带有源码提交标识。生产服务部署、应用覆盖安装和推送远程仓库不属于本次打包操作。
