# 0.18.0

界面开始说英文了：设置里多了一个「界面语言」选项，默认 English，可切回中文；顺手把项目按 MIT 协议开源——LICENSE、双语 README、当前版本的界面截图都补齐了。

## 新增

- **界面多语言（第一阶段）**：新增轻量 i18n 框架（`src/lib/i18n.ts`）——默认英文，语言存 localStorage；翻译 key 直接用中文原文，英文词典查不到就回退中文，未迁移的界面不会崩。设置 → 外观新增「界面语言」下拉（English / 中文），切换立即生效、全树重渲染。本轮已翻完：主导航、页头、会话列表、侧栏分组与徽章、桌面通知文案、设置全部子页（登录、账号与安全、通知规则、本机执行与采集、Android 后台提醒）。会话详情、任务、日历、统计等大页面暂未迁移，英文模式下暂时保持中文，后续版本逐个补。
- **MIT 许可**：根目录新增 `LICENSE`（© 2026 wenbo），`package.json` 与 `src-tauri/Cargo.toml` 补 license 字段（保留 `private: true` 防误发 npm）；中英文 README 各加许可证一节与免责声明（与 Anthropic / OpenAI / 智谱 / 字节 / 腾讯无关联，只读本机日志，部分集成走未公开接口）。依赖侧确认无 GPL/AGPL，选 MIT 不影响任何依赖。

## 改进

- **README 改版**：顶部加「中文 | English」双页导航（新增 `README.en.md`）；新增功能一览与「界面预览」区，放 7 张按当前代码 + 假数据渲染的界面截图（会话总览、会话详情、手机端批授权、任务、目标、日历、统计），替换掉 0.5.0 时代的旧图；删掉与 `docs/releases/` 重复的版本历史长段。
- **GitHub 社交预览图**：`assets/branding/social-preview.png`（1280×640），icon + 桌面/手机截图合成，手动上传到仓库 Settings → Social preview 即可。

## 升级

服务端无改动，数据库无迁移，直接升级客户端即可。升级后界面默认变成英文；想要中文，到 设置 → 外观 → 界面语言 切回「中文」。
