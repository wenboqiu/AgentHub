# 0.11.9 会话列表：平板也常驻、宽度可拖、顶栏横贯全宽

只换客户端安装包即可，无服务端改动。

- **平板也看得到会话列表**：左侧会话列表之前只在桌面端渲染，安卓平板上从气泡点进对话流后完全找不到列表；现在改成按视口宽度决定形态，不看平台——比 760px 宽（电脑、安卓平板横屏 / 竖屏）就常驻左侧，手机宽度放不下才收成从左滑出的抽屉（头部「会话列表」按钮打开，有待处理会话时按钮上挂红点；选中会话或点遮罩自动收起）。
- **列表宽度可拖**：侧栏右缘分隔线是一条拖动把手，鼠标 / 触屏按住左右拖即可调宽（200–560px，且不超过视口一半），松手记住；双击恢复默认 276px，电脑端还支持 ← → 微调（Shift 大步进）。窗口变窄时自动收到允许的上限。
- **顶栏横贯全宽**：顶栏（返回 / 项目名 / 机器状态 / 刷新）不再只压在对话列上，而是横贯整页，会话列表从顶栏下沿开始；长对话滚动时顶栏粘在顶部，列表和拖宽把手一起跟住，不脱节。
