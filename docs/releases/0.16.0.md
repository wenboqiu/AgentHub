# 0.16.0

任务单工作流理顺：会话等你拍板时直接说「等你决定」，不再转手派给 agent；挂着任务的会话跑完不再自动滚出「跟进」单；任务单全文看得到了。另外角色可以设思考强度。

## 新增

- **「等你决定」卡**：会话结尾在等人拍板（「需要你定夺 / 决定 / 确认」，否定句不算）时，出一张「等你决定」卡而不是派活单，排在其它建议前面。卡片默认展开那段问题原文；主按钮「去会话回复」，在原会话答一句它就带着上下文接着做；真要另起一件事才「转成任务单」；答过了点「已处理」。会话页底部入口直接显示「它在等你决定」。
- **建议卡就地看详情**：建议阶段多了「看详情」，规则稿的说明（按 Markdown 渲染）、清单、证据当场展开，不必先生成任务单才知道要不要做。
- **角色思考强度**：角色可设置思考强度（Claude / Codex / ZCode）。
- **任务行临近截止换底色**：24 小时内琥珀色，已过期红色。

## 修复

- **任务单「派生」成一条停不下来的链**：挂了任务的会话跑完，回复里没有明确下一步时不再出兜底「跟进」——下一步是验收 / 打回。以前验收类会话每轮都写长总结，就会滚成「核对上一轮的核对」。
- **会话标题和任务单说明里「来源会话：来源会话：…」一层套一层**：派任务的会话改为保留服务端起的标题（任务标题），不再被 hook 抢先上报的首条消息（任务说明原文）顶掉；规则档说明出处改写「来源：任务 #N「标题」」。
- **兜底标题是一串说明原文**：改取回复里的小标题 / 第一行，截断时带省略号。
- **任务单内容被截断**：标题、验收清单、说明的输入框随内容长高，不再藏掉后半截。
- **追问落回执行端默认模型**：追问沿用会话上一轮的模型。

## 升级

服务端有改动（规则档、会话标题合并、`session_proposals.kind` 新增 `decide`，启动时自动迁移 CHECK 约束），**先升服务端再升客户端**。已有的旧会话标题和旧建议不会自动改，只对新生成的生效。
