# 0.15.1

修几处「改了不刷新」，以及 WorkBuddy / ZCode 装在别的盘时探测不到。

## 修复

- **WorkBuddy / ZCode 装在非默认位置探测不到**：以前只在 `%LOCALAPPDATA%\Programs` 和 `C:\Program Files` 下找，装在 `D:\Program Files\WorkBuddy` 这类位置时，电脑既不上报这个工具，也派不了活。现在固定位置找不到时，读 Windows 卸载注册表里的 `DisplayIcon` 反推安装目录。
- **新建项目后任务页不刷新**：从设置页回到主界面时，项目列表跟角色、项目经理一起重拉。
- **别的设备改了角色 / 项目不刷新**：角色、项目、项目经理设置有变动时，服务端推给同账号的所有设备，各自实时重拉。
- **电脑从离线变成「开着，没开远程执行」时任务详情不刷新**：这类电脑连上 / 断开时服务端单独推一声，打开着的任务详情重拉电脑列表。

## 升级

服务端和客户端都有改动，**先升服务端再升客户端**。只升客户端也不会出错，只是别的设备的改动、电脑状态变化仍要等重连才看得到；WorkBuddy 探测的修复只在客户端，不依赖服务端。

## 验证

- 前端 `tsc --noEmit`、`vite build` 通过；根目录 `npm test` 69 项通过；`cargo test` 188 项通过（新增注册表解析用例，用的是 homelab 上 `reg query` 的真实输出）。
- server 测试在 homelab 的 Postgres 上跑 prefs / projects / roles / assistant 35 项全过（新增 catalog 推送用例）。
